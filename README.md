# Windows Dock

一个仿 macOS Dock / MyDockFinder 的 Windows 桌面 Dock 栏(WPF 原生实现,无第三方依赖)。

## 功能

- **自动发现桌面应用**:启动时扫描「用户桌面 + 公共桌面」,自动把应用加入 Dock
  - 识别 `.lnk` 快捷方式(自动解析真实目标)和直接放在桌面的 `.exe`
  - **文件不添加**:文档、图片、压缩包等一切非应用文件自动忽略;指向文件夹的快捷方式也不添加
  - 自动过滤卸载器(uninstall / 卸载等)
- **格子化布局**:每个图标占据固定宽度的格子(图标 + 间距),不再前后紧贴
- **自动分页**:图标多于一页时自动分页(每页数量 = 格子能放下的个数),末页自动变窄。
  翻页方式:鼠标滚轮,或悬停后点击两侧箭头(悬停时浮现,位于独立列内,与图标不重叠);
  面板下方有页码圆点指示当前页
  - 切页过渡(2026-10-08 重做):只有图标列表参与过渡(方向位移 + 淡入滑入),
    玻璃面板/固定板块全程稳定不闪;末页宽度与位置变化随切页平滑动画
- **固定的右侧板块**:分割线之后常驻三个系统入口——**文件资源管理器 | 此电脑 | 回收站**,
  每一页都能看到,点击直接打开
- **桌面变化自动同步**:通过 FileSystemWatcher 监听桌面,新建/删除应用快捷方式后自动更新 Dock(带防抖)
- **macOS 风格放大动画**:鼠标掠过时图标平滑放大(从面板顶部凸出)、邻近格子被"挤压",带余弦衰减曲线
- **高清图标**:按 256px 提取应用图标(修正了 SHDefExtractIcon 的 nIconSize 高低字顺序),
  高质量缩放渲染;「此电脑」「回收站」使用 imageres.dll 系统图标
- **启动弹跳动画**:点击图标启动应用时图标上下弹跳
- **运行指示灯**:图标下方的小圆点实时显示应用是否正在运行(每 2 秒检测)
- **半透明玻璃背景**:WPF 渐变玻璃底,桌面可直接透过 Dock 看到;圆角、悬停高亮
- **托盘图标**:显示/隐藏、自动隐藏、重新扫描、退出
- **自动隐藏**:鼠标靠近屏幕底边自动弹出,离开后自动缩回
- **仅桌面显示**:前台是桌面(Win+D / 全部最小化 / 点击桌面)时 Dock 从底部滑入;
  激活任何**可见的**应用窗口立即滑出,不遮挡应用内容(2026-10-07 定稿,替代旧的常驻桌面层方案)
  - 判定原则(2026-10-08 修订):只有「看得见的真实应用窗口」才收起 Dock。
    系统菜单(经典 `#32768` 与 Win11 新式 `XamlExplorerHostIslandWindow_WASDK`,
    即桌面/桌面图标右键菜单)、不可见或被 DWM 遮蔽的前台(如微信常驻的隐形
    辅助窗口)、窗口切换瞬间的悬空前台,一律冻结当前状态 —— 修复了「右键弹出
    菜单时 Dock 消失」与「Dock 在桌面上反复弹出/缩回」两类抖动
- **开机自启**:写入 HKCU Run 注册表键,无需管理员权限

## 使用

```bash
# 构建(需要 .NET 9 SDK)
dotnet build WindowsDock -c Release

# 运行
WindowsDock\bin\Release\net9.0-windows\WindowsDock.exe
```

程序启动后常驻托盘,Dock 显示在主屏底部居中。

## 设置

**右键点击 Dock 空白处**:

| 设置 | 说明 |
|---|---|
| 自动隐藏 | 鼠标靠近屏幕底边时弹出,离开后隐藏 |
| 开机自启 | 写入注册表 Run 键 |
| 图标大小 | 32 / 36 / 40 / 48 / 56 / 64 px |
| Dock 最大宽度 | 屏宽的 55% / 65% / 75% / 85%(同时决定每页格子数;超过自动分页) |
| 放大倍数 | 1.25x ~ 2.0x |
| 重新扫描桌面 | 手动触发一次桌面扫描 |

**右键点击某个图标**:打开 / 从 Dock 中移除(移除会记住,之后不会再被自动加回来)

**托盘图标**:双击或菜单可切换显示/隐藏

## 配置文件

`%APPDATA%\WindowsDock\config.json` — 图标大小、放大倍数、自动隐藏、开机自启、移除列表。
删除该文件即可恢复默认(被移除的应用会重新出现)。
`%APPDATA%\WindowsDock\log.txt` — 运行日志(扫描结果、错误等)。

## 已知限制

- 仅支持主显示器
- UWP / 商店应用不会出现在 Dock(只扫描桌面上的传统应用)
- 背景为半透明玻璃(无模糊):Windows 11 24H2 上 DWM 的 accent 模糊已失效
  (会渲染成不透明黑块,且会破坏分层窗口的 alpha 通道),系统背板亚克力
  在 WPF 窗口上也无法透出内容,因此采用纯 WPF 半透明渐变底
- 隐藏 Windows 自带任务栏请在「任务栏设置」中手动开启自动隐藏

## 项目结构

```
WindowsDock/
├── App.xaml(.cs)              入口:单实例互斥锁、全局异常处理、托盘、自启
├── Models/
│   ├── DockItem.cs            Dock 图标项(图标、运行状态)
│   └── AppSettings.cs         配置模型 + JSON 持久化 + 日志
├── Services/
│   ├── DesktopScanner.cs      桌面应用扫描(只挑应用,过滤文件)
│   ├── LnkResolver.cs         COM IShellLink 解析 .lnk 真实目标
│   ├── IconExtractor.cs       SHDefExtractIcon 高清图标提取
│   └── AppMonitor.cs          EnumWindows 检测正在运行的应用
└── Views/
    ├── DockWindow.xaml(.cs)   Dock 主窗口:放大动画、毛玻璃、自动隐藏
    └── TrayController.cs      托盘图标
```

## 实现备注

- 图标提取曾尝试 `IShellItemImageFactory`,在 .NET 9 下会触发 coreclr.dll
  访问冲突(0xC0000005)直接杀死进程且无法捕获,已改用 `SHDefExtractIcon`
- 每个图标的提取放在独立 STA 线程并带 3~4 秒超时,防止个别应用
  (OneDrive 按需文件、被杀软拦截的 exe)卡住整个扫描
- 背景透明:曾依次尝试 accent 亚克力/blurbehind、`DWMWA_SYSTEMBACKDROP_TYPE`
  系统背板,在 Win11 24H2 + .NET 9 组合下均无法透出内容(accent 还会毁掉
  分层窗口的 alpha),最终采用 `AllowsTransparency + 半透明渐变` 方案
